> **ℹ️ Info**
>
> Create a new **users **record for an existing user to create a new user account the next time the user logs in.
> 
> The new user account will need to have its Role set, re invited to Collections, and have assets like Shared Gallery Credentials / Database Connections, and DCM Connections shared with them.
