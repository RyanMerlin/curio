## Published Tree Blueprint

### Product Tree

- `product-tree` is the default demo branch for product-oriented examples.
- Use this branch for synthetic docs that demonstrate intake, routing, staging, and publication.

### Topic Tree

- `topic-tree` holds cross-cutting reference material in the demo workspace.

### Use Case Tree

- `use-case-tree` captures example end-user workflows and scenarios.

### Account Tree

- `account-tree` holds account-specific examples and demo customer content.
